# 品牌资源

统一采用黑底 `#111111`、白色 `#F2F2F2` 和红点 `#E5484D`。网页的可选强调主题不改变品牌标识。

| 文件                  | 用途                              | 编辑方式                             |
| --------------------- | --------------------------------- | ------------------------------------ |
| `icon.svg`            | UC 字母、十字键与圆按钮的方形标识 | 唯一方形图标源，直接修改 SVG 路径    |
| `icon0.png`           | PS5 安装图标，512×512             | 由 `icon.svg` 导出                   |
| `../../web/icon.png`  | 网页页签，128×128                 | 由同一 `icon.svg` 导出               |
| `../../web/brand.svg` | 网页页头的横向字标                | 白色 Trebuchet MS 小写字标与固定红点 |
| `banner.svg`          | README 横幅源                     | 保留字标、一行标语及低对比红色波纹   |
| `banner.png`          | README 横幅，2048×640             | 由 `banner.svg` 导出                 |

旧橙底手柄图、重复模板和原始位图不再使用。设备列表里的线性手柄是功能图标，不属于品牌变体。方形图标没有文字字体、阴影或渐变，适合静态 PS5 图标和小尺寸网页页签；Banner 保留波纹层次。

在仓库根目录重新生成所有 PNG：

```sh
npm ci --ignore-scripts --no-audit --no-fund
node tools/build_branding.js
```

脚本复用已有 Playwright 开发依赖，查找本地 Chrome/Chromium；可通过 `CHROME_PATH` 指定浏览器。不会访问外部图片服务。字标使用本机 Trebuchet MS 字体，缺失时由浏览器回退，生成后需检查字体效果。编辑后同时提交 SVG 和派生 PNG，CI 直接嵌入已提交资源，不在 payload 构建中重新绘图。
