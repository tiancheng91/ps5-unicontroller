# H5 重写与验收

本轮以已确认的 [骨架](prototypes/ui-skeleton.html) 为基准重写产品HTML与CSS，移除旧的control／controller／shared目录。产品规范与文件边界见根目录 [design.md](../design.md)。

## 已实现

- 桌面左侧导航、手机顶部导航；手柄、模拟手柄、日志、设置四个清晰入口。
- 蓝牙与USB统一设备行，按实际身份稳定复用DOM；无大幅手柄插图、首页账号选框或技术JSON。
- 新增设备与详情侧栏；焦点进入、Tab限制、Esc关闭、入口恢复及方向导航的模态范围。
- 蓝牙启用完成后才开始扫描；发现新设备不自动连接，必须点选其结果ID后才配对。可单独停止搜索，已有连接与配对任务不受影响。
- 设置中集中服务启停、默认震动／翻转／映射、自动启动与日志级别；浏览器外观立即生效，硬件设置显式保存。
- 日志独立分区及完整诊断导出。模拟手柄独立页面，保留PS键与输入释放逻辑。
- 中英文首选语言和本地外观偏好；离线CSP版本Alpine，不放宽脚本策略。

请求令牌、超时、异步操作epoch和模拟输入的取消清理由独立逻辑层保留，不因视觉重写更改PS5注册、账号绑定或蓝牙协议。

## 检查项目

1. 浏览器无CSP／Alpine告警，未知设备文本不能生成HTML。
2. 多次轮询不替换聚焦的设备按钮；侧栏不能聚焦或操作背后的按钮。
3. 只打开新增侧栏不发送写操作；启用服务与扫描按顺序发出，配对只由点选发起；扫描期间倒计时逐秒变化，停止扫描不调用停用蓝牙。
4. 蓝牙与USB状态分别控制启停，失败不能以示例数据替代。
5. 默认映射值在option渲染后保持正确；保存失败保留编辑内容，外观切换不触发硬件操作。
6. 标准Gamepad确认边沿只触发一次；原生select仍能编辑，模拟输入与页面导航隔离。
7. 模拟手柄PS按住／释放、后台释放和取消后的迟到创建清理。
8. 手机各分区与侧栏无横向溢出；离线资源逐字节匹配，旧资源URL不再提供。

PS5实机尚需确认：WebView字体与焦点、Gamepad API／系统键表现、确认框可操作性、休眠恢复和原装手柄共存。Chrome通过不代表这些项目已验收。
