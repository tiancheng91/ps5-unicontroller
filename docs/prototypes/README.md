# UI 布局骨架（已确认参考）

打开 [ui-skeleton.html](ui-skeleton.html)。它是独立、可离线打开的低保真网页，不加载现有 UI、Alpine 或 API，不随 payload 打包，不代表已确认的产品设计。

需要浏览器地址预览时，从仓库根目录运行：

```sh
python3 -m http.server 17457 --bind 127.0.0.1 --directory docs/prototypes
```

访问 `http://127.0.0.1:17457/ui-skeleton.html`。

顶部“示例状态”仅是评审工具，可查看有设备、无设备和蓝牙未启用的布局。左侧导航切换手柄、模拟手柄、日志及设置；手机使用顶部横向导航。新增设备和设备详情使用侧边面板。搜索、配对、设置开关只展示本地交互，不执行操作或持久化配置。

本轮评审页面分区、内容顺序、入口位置、桌面/手机布局。主题色、图标、实际设备配置项、账号策略和 API 实现不在本原型中确定。该布局已确认，产品页面已按此结构实现于 `web/index.html` 和 `web/controller.html`；本文件保留为低保真参考。
